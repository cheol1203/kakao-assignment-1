## AI 활용 내역

### Todo CRUD 구현하기

* AI 활용 내용 :
  다음 프롬프트를 사용하여 Todo 앱의 기본 레이아웃과 CRUD 기능을 구현했다. 입력창, 추가 버튼, Todo 목록, 수정 / 완료 / 삭제 버튼이 포함된 `index.html`, `style.css`, `app.js` 전체 코드를 받았다. Todo 추가, 수정, 완료, 삭제 기능이 정상적으로 동작하는지 확인했다. 입력값이 비어 있을 때 안내 메시지가 표시되는지도 테스트했다.

```text
Todo 앱의 HTML 레이아웃과 기본 CRUD 기능을 만들어줘.

- 텍스트 입력창과 추가 버튼으로 Todo를 생성할 수 있어야 해
- 생성된 Todo는 목록으로 표시되고, 각 항목마다 수정 / 완료 / 삭제 버튼이 있어야 해
- 입력값이 비어있으면 Todo가 생성되지 않고 안내 메시지를 표시해줘
- 완료된 Todo는 텍스트에 취소선이 표시되어야 해
```.

### 상태별 필터링 기능

* AI 활용 내용 :
  다음 프롬프트를 사용하여 전체 / 진행 중 / 완료 탭 기능을 추가했다. AI를 통해 `data-filter` 속성을 가진 필터 버튼과 현재 선택된 필터를 저장하는 `currentFilter` 변수를 활용한 코드를 받았다. 필터 탭을 클릭했을 때 선택된 탭에만 `active` 클래스가 적용되는지 확인했다. 또한 진행 중 탭에서는 완료되지 않은 Todo만, 완료 탭에서는 완료된 Todo만 표시되는지 테스트했다.

```text
기존 코드에 상태별 필터링 기능을 추가해줘.

- 전체 / 진행 중 / 완료 탭을 클릭하면 해당 상태의 Todo만 표시돼야 해
- 현재 선택된 탭은 시각적으로 구분되는 스타일이 적용되어야 해
```

### 일간 뷰 기능

* AI 활용 내용 :
  다음 프롬프트를 사용하여 날짜별 Todo 관리 기능을 추가했다. AI를 통해 화면 상단에 선택된 날짜를 표시하고, 이전 / 다음 버튼으로 날짜를 이동하며, Todo 생성 시 현재 선택된 날짜를 함께 저장하는 코드를 받았다. 날짜를 이동했을 때 해당 날짜에 맞는 Todo만 보이는지 확인했다. 오늘 날짜에 만든 Todo가 다른 날짜에서는 보이지 않고, 다시 오늘 날짜로 돌아왔을 때 정상적으로 표시되는지 테스트했다.

```text
기존 코드에 일간 뷰 기능을 추가해줘.

- 화면 상단에 오늘 날짜를 표시하고, 이전 / 다음 버튼으로 날짜를 이동할 수 있어야 해
- Todo를 생성할 때 현재 선택된 날짜를 함께 저장해야 해
- 선택된 날짜에 해당하는 Todo만 목록에 표시돼야 해
```

### 로컬스토리지 연동 기능

* AI 활용 내용 :
  다음 프롬프트를 사용하여 로컬스토리지 저장 및 불러오기 기능을 추가했다. AI를 통해 `JSON.stringify()`로 Todo 배열을 저장하고, `JSON.parse()`로 다시 불러오는 코드를 받았다. Todo를 추가, 수정, 완료, 삭제한 뒤 새로고침했을 때 데이터가 유지되는지 확인했다. 또한 로컬스토리지에서 불러온 Todo의 id가 새로 추가되는 Todo와 겹치지 않도록 `nextTodoId`가 가장 큰 id보다 1 크게 설정되는 흐름을 확인했다.

```text
기존 코드에 로컬스토리지 연동 기능을 추가해줘.

- Todo를 추가 / 수정 / 삭제 / 완료 처리할 때마다 로컬스토리지에 저장되어야 해
- 페이지를 새로고침하면 로컬스토리지에서 데이터를 불러와 목록을 복원해야 해
- 데이터는 JSON.stringify / JSON.parse를 사용해서 저장하고 불러와줘
```

### 주간 뷰 기능

* AI 활용 내용 :
  다음 프롬프트를 사용하여 도전 기능인 주간 뷰를 추가했다. AI를 통해 이번 주 월요일부터 일요일까지 날짜를 가로로 나열하고, 이전 주 / 다음 주 버튼으로 주차를 이동하며, 날짜별 Todo 개수를 표시하는 코드를 받았다. 주간 뷰에서 월요일부터 일요일까지 날짜가 올바르게 표시되는지 확인했다. 이전 주와 다음 주 버튼을 눌렀을 때 주차가 이동하는지, 날짜를 클릭했을 때 해당 날짜의 Todo만 표시되는지 테스트했다. Todo를 추가하거나 삭제했을 때 날짜 아래 Todo 개수가 바로 갱신되는지도 확인했다.

```text
기존 코드에 주간 뷰 기능을 추가해줘.

- 이번 주 월요일부터 일요일까지의 날짜를 가로로 나열해줘
- 이전 주차, 다음 주차로 넘길 수 있는 버튼을 만들어줘
- 날짜를 클릭하면 해당 날짜의 Todo만 목록에 표시돼야 해
- 각 날짜 아래에 해당 날짜의 Todo 개수를 표시해줘
- 오늘 날짜는 시각적으로 구분되는 스타일을 적용해줘
```

## 구현하면서 고민한 점

* 고민한 점 :
  주간 뷰를 구현할 때 이번 주의 시작 날짜를 월요일로 계산하는 부분이 헷갈렸다. 특히 JavaScript에서 일요일은 `getDay()` 값이 0이기 때문에 월요일 기준으로 계산하는 로직이 필요했다.

* 해결 방법 :
  선택된 날짜가 포함된 주의 월요일을 구하는 `getMondayOfWeek()` 함수를 만들었다. 일요일인 경우에는 6일 전으로 이동하도록 처리하고, 그 외 요일은 월요일과의 차이를 계산해 해당 주의 월요일을 구했다.

* 고민한 점 :
  Todo를 추가하거나 삭제했을 때 목록만 바뀌는 것이 아니라 주간 뷰의 날짜별 Todo 개수도 함께 바뀌어야 했다.

* 해결 방법 :
  Todo를 추가하거나 삭제한 뒤 `renderTodoList()`만 호출하지 않고, 날짜별 개수를 다시 계산할 수 있도록 `renderWeekDateList()`도 함께 호출했다.
